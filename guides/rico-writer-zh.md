# Rico Writer - 中文人话写作与去 AI 味编辑

对中文文本做新写、扩写、润色或诊断，让文字具体、清楚、有判断。保留事实和作者的表达习惯，去掉 AI 生成文字的明显痕迹。

---

## 这个技能能做什么？

### 核心功能

1. **去 AI 味润色** - 删除二元对比句式（"不是A，而是B"）、伪洞察提示词（"本质上""更重要的是"）、训话开头（"记住这句话"）、无依据夸张（"必备神器"）
2. **事实安全的改写** - 名称、数字、时间、技术术语、测试条件和来源全部保留。作者的立场和确定程度不被抹平或夸大（"可能"不会改成"已经"）
3. **拟人化动词清理** - "吃参考图" → "支持参考图输入"，"给模型喂素材" → "把素材提供给模型"。按搭配和语境判断，不设单字禁用表
4. **四种工作模式** - 从材料新写、扩写、润色、引用原句诊断
5. **不干涉结构** - 不规定开头写法、文章结构和结尾方式，跟随作者的材料走

### 适用场景

- 润色一篇读起来像 AI 写的草稿，同时保留你的判断
- 把简短笔记扩写成完整文章，不编造经历和数据
- 把产品评测改成 X/Twitter 推文，保留立场
- 诊断一篇文章为什么不对劲，给出具体改法

---

## 触发方式

**自然语言（典型请求）：**

```
帮我把这段文章去 AI 味润色一下
把我的笔记扩写成一篇 800 字的公众号文章
这段文案帮我写得像人说话一点
把这篇评测改写成推文，保留我的判断
诊断一下这篇文章哪里有 AI 味
```

**不触发的情况：**

- 纯翻译（把这段翻译成英文）
- 只做校对（帮我检查错别字）
- 只整理格式（把这个 markdown 排版整理一下）

## 工作原理

### 风格规则（简版）

| 类别 | 规则 | 示例 |
| ---- | ---- | ---- |
| 对比句式 | 直接陈述判断 | "去 AI 味不是改口语，而是保住判断" → "改稿时要保留作者的判断" |
| 拟人化动词 | 说清功能实际做什么 | "吐 GIF" → "生成 GIF" |
| 标点 | 双引号 ""，不用直角引号「」，原创正文不用破折号 | 用逗号或断句代替 |
| 比较 | 判断要写清场景和依据 | 没有材料支持不写"效率翻倍""必备神器" |
| 结构 | 不强加开头结尾套路和文章模板 | 开头和结构跟随作者的材料 |

### 内容边界

- 不编造经历、使用时长、引语、数据或产品功能
- 决策阈值（"先攒够 X 小时再买"）需要依据，扩写时不会凭空补出
- 转述他人观点和独创分析时交代归属，直接引用保留来源
- 第一人称只在原材料是亲历时保留（"我测了"需要有真实测试）

### 交付方式

默认只交付成稿。用户要求分析或对照时，才附相应内容。

## 评估结果

用 3 个任务（去 AI 味润色、笔记扩写、评测改推文）做了带/不带技能的对照测试，共 31 条客观断言：

- **带技能：100% 通过率** vs 不带技能：87.3%
- 技能防住了 baseline 产生的问题：编造决策阈值、拟人化动词、破折号依赖、擅自添加原文没有的建议
