Typography

Mona Sans as primary typeface (Inter substitute). Wide weight range with precise letter-spacing for a modern, organized voice.

Guidelines

Do's & Don'ts

Do — Embrace
  • Deep Space (#0d1117) as primary background
  • Ghost White (#ffffff) for all primary text
  • Spring Green (#08872b) for primary CTAs only
  • Polar Blue (#8dd6ff) for links and interactive icons
  • 6px radius for buttons, 24px for cards
  • 4px-based spacing with ample breathing room
  • Translucency and glows over heavy shadows
Don't — Avoid
  • Bright saturated backgrounds
  • Generic gray borders on interactive elements
  • Hard sharp corners on cards or buttons
  • Overly large decorative drop shadows
  • Dense packing without breathing room
  • Font families outside Mona Sans / Inter
  • Mono fonts for non-code content
